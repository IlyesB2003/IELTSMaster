# IELTS Master — Independent Audit (2026-11-25)

Scope: the project at `~/Desktop/IELTSMaster` (5 commits, `c63232e` HEAD, ~11,800 lines of Swift), audited against the original specification. Read from source; **not** re-compiled or re-run in this audit (see "What was not verified").

## Verdict

The engineering skeleton is solid and genuinely native (SwiftUI, SQLite WAL, AVFoundation, Speech, Keychain, Ollama client, deterministic scoring). **The content layer is not**: the "30 distinct, quality-validated mock exams" are one template filled 30 times. That is the single biggest gap between the project and the specification, and the documentation overstated it. README and ENGINEERING_REPORT have been corrected in place.

## Findings (most severe first)

### 1. Mock exam bank is one template ×30 — CRITICAL
`Sources/IELTSCore/Curriculum/MockExamBank.swift` builds every exam from the same `buildListeningParts` / `buildReadingPassages` functions, substituting ~20 blueprint fields (city, scientist, key terms, numbers).
- Same 40 Reading question stems in every exam; most answers identical across exams (e.g. R03 FALSE "not uniform", R09 "staff training", R11 "selection bias", R29 "adaptive governance", R34 "interoperability").
- Same Listening Part 1 call in every exam; answers "Thursday", "laptop", "north", "vegetarian", "digital" repeat in all 30. After one exam, a learner can answer Q2, Q5, Q6, Q8 and Q9 of every other exam without listening.
- Passages are 4 paragraphs of ~60 words (~250 words). Real IELTS Academic passages run roughly 700–900 words (2,150–2,750 for the three).
- Substitution produces ungrammatical or meaningless text, e.g. exam 3: "integrating aqueduct into established workflows can stabilize seasonal output".
- Several MCQs have only 3 options. IELTS Reading uses 4 (A–D), and in Listening 3 is valid only for some tasks.
- **Effect on learning:** scores from exam #2 onward measure memory of the template, not reading or listening ability. That corrupts the adaptive engine, the dashboard trends and the band estimates.

### 2. Validator can't see the problem — HIGH
`ContentValidator.validate(exam:)` checks duplicate prompts within one exam only. `validateBank` doesn't compare exams with each other, which is why it reported "30/30, zero duplicates". The fix is a cross-exam check: normalized question-stem similarity (for example, shingled Jaccard > 0.6 = duplicate) and answer-key overlap.

### 3. Partial practice sets are scaled to a 40-item band — MEDIUM
`IELTSScoringEngine.gradeObjectiveModule` rescales any subset (for example, a 13-question passage) to /40 and returns a band. A single passage can't support a band estimate with any confidence. Return the raw score, and show a band only for full 40-item tests (or label it "very low confidence").

### 4. Documentation overstated verification — MEDIUM (fixed in docs)
"2,400 verified questions", "30 distinct" and "30/30 QA passed" were presented as quality guarantees. Corrected in `README.md` and `Docs/ENGINEERING_REPORT.md`; nothing else in those files was changed.

## What checks out
- **Overall rounding:** `floor(x·2 + 0.5)` gives the official results for means of four half-bands: 6.125→6.0, 6.25→6.5, 3.875→4.0, 6.75→7.0. This matches ielts.org / British Council examples.
- **Writing:** Task 2 counts double (official weighting). Rounding within a task isn't published, so it's an estimate, and it's labeled as one.
- **Raw→band tables:** Listening (16→5, 23→6, 30→7, 35→8) and Academic Reading (15→5, 23→6, 30→7, 35→8) agree with every official anchor published on ielts.org. The intermediate rows follow the Cambridge practice-book tables. IELTS states exact thresholds vary by test version, so "approximate" is the right label.
- **Answer checking:** T/F/NG and Y/N/NG shorthand normalized; word limits enforced.
- **Speaking:** pronunciation band withheld when only a transcript is available. This is the honest behaviour the spec asked for.
- **Native stack:** a Mach-O arm64 binary exists in `.build/debug` and in `dist/IELTSMaster.app`, so the project has compiled at least once on this Mac.
